# Clinical Trial Data Analytics Dashboard

Analysis of a synthetic clinical trial dataset using Excel and Power BI.

## Overview

Analyzed dropout, adverse events, enrollment trends, and patient vitals across 1000 subjects, 50 sites, and 3 treatment groups.


## Tools

* Excel: Data cleaning, pivot tables, analysis
* Power BI: DAX, KPIs, charts, interactive dashboard


## Note

Synthetic data used for learning purpose. No real patient data is used.
